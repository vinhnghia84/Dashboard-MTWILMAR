# MT Wilmar – Sales Performance

Dashboard doanh số kênh siêu thị (SBU & NBU), chạy trên GitHub Pages.

Dữ liệu được mã hóa (AES-256-GCM) trong `data.enc`; chỉ tài khoản được cấp mới mở được.
`keys.json` chứa khóa đã được khóa lại bằng mật khẩu của từng tài khoản.
Dữ liệu được cập nhật tự động từ máy của người quản trị.
