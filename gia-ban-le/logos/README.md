# Logo thương hiệu

Đặt file logo vào thư mục này, đúng tên file dưới đây (chữ thường). Nên dùng PNG nền trong suốt, hình vuông, tối thiểu 128×128px.

| Thương hiệu | Tên file |
|---|---|
| Simply | `simply.png` |
| Neptune | `neptune.png` |
| Neptune Olive | `neptune-olive.png` |
| Meizan | `meizan.png` |
| Cái Lân | `cai-lan.png` |
| Kiddy | `kiddy.png` |
| Olivoilà | `olivoila.png` |
| Orchid | `orchid.png` |

Thương hiệu chưa có file sẽ tự hiện ô màu với chữ viết tắt như cũ.
Muốn dùng file SVG hoặc tên khác: khai báo trong `config.js`, ví dụ `brandLogos: { simply: 'logos/simply.svg' }`.
